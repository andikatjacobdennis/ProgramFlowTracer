ProgramFlowTracer Trace Viewer

Open a trace

Point the viewer at a run directory produced by ProgramFlowTracer — typically <YourApp>/.flowtrace/runs/<run-guid>/.

…or drag the run folder anywhere onto this page.

What the viewer reads
  • events.jsonl — required. One MethodEnter / MethodExit / Exception record per line.
  • run.json — optional run metadata (application, timings, dropped-event count).
  • objects/*.json — optional. Large captured values spilled out of the event stream; loading them lets the viewer resolve objectId references inline.

The viewer keeps a handle to the folder location you pick, so Reload re-reads it in place — new runs and events appended since show up without re-picking anything, and there is never a copy of the trace to package up and keep in sync.

Everything is parsed in your browser. No file ever leaves this machine.
